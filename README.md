# 排水管道缺陷目标检测数据集
## 一、数据集信息表
|项目|详情|
| ---- | ---- |
|数据集名称|排水管道缺陷目标检测数据集（CCTV管道内窥）|
|图像总量|19049张原图，无数据增强，总大小2.21GB|
|采集方式|管道内窥CCTV检测图像，市政排水管道内部实拍画面|
|标注依据|《城镇排水管道检测与评估技术规程》CJJ181-2012|
|标注类别|合计17类：15类规程内管道缺陷 + 1类规程外异物缺陷 + 1类正常管道接口样本|
|类别清单|PL破裂、BX变形、TL接口材料脱落、CK错口、AJ支管暗接、CR异物穿入、CJ沉积、FS腐蚀、ZW障碍物、SG树根、QF起伏、CQ残墙坝根、SL渗漏、JG结垢、TJ脱节、YW异物、Joint管道接口（正常类别）|
|标注格式|VOC xml标注格式|
|适用任务|管道内窥图像多类别缺陷目标检测|

## 二、数据集![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/96aa654f713340b1b08b3d641a9ac1fa.jpeg)

**标题：市政排水管道CCTV内窥缺陷检测数据集｜17类管道病害识别**
>正文摘要：
本套排水管道缺陷数据集共19049张原始内窥图像，未做任何数据增强处理，严格依据国内《城镇排水管道检测与评估技术规程》CJJ181-2012进行标注。数据集包含17个类别，涵盖15项规范定义管道病害、1类异物缺陷以及正常管道接口样本。
数据集采用VOC（xml）标注格式，图片为管道CCTV机器人内窥实拍原图，可直接导入YOLO、Faster R-CNN等目标检测模型训练，可自动识别管道破裂、变形、沉积、树根、渗漏、错口等各类管道病害，用于市政管网智能化检测系统研发。

## 三、数据集应用价值
1. **市政管网自动化检测**：替代人工阅片，自动识别管道内部各类病害，大幅降低排水管道CCTV检测报告人工判读成本，提升管网检测效率。
2. **城市排水运维数字化**：支撑城市智慧排水平台，自动评估管道病害等级、定位缺陷位置，辅助管网养护、维修、病害风险评估。
3. **算法研究与模型训练**：真实管道内窥实拍场景，存在暗光、污渍、遮挡、反光等复杂干扰，适合研究小目标、暗光环境下多类别缺陷检测算法。
4. **行业标准化AI落地**：完全对标国内CJJ181-2012行业规范，模型输出缺陷类型直接匹配市政工程验收标准，便于工程项目落地。
5. **管网病害统计分析**：可基于模型批量识别大量管道视频/图片，统计区域内各类病害分布，支撑管网健康评估、病害溯源分析。

## 四、适用群体
1. 市政排水、水务集团、管网运维公司，开发管道内窥AI判读系统；
2. 计算机视觉算法团队、智慧水务项目集成商，研发管道缺陷检测产品；
3. 高校、科研院所，给排水、遥感、计算机视觉专业课题、毕业设计、竞赛；
4. 第三方管道检测工程公司，用于AI辅助CCTV检测判读工具开发；
5. 算法研发人员，学习复杂暗光场景多类别目标检测模型训练。
